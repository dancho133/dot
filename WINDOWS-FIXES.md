# Мелкие поломки Windows, которые уже чинили

Не про dot, но про эту машину. Чтобы в следующий раз не искать заново.

## Win+V (журнал буфера обмена) перестал открываться

**16.07.2026.** Панель не появлялась вообще, хотя:

- служба `cbdhsvc_*` — Running,
- в параметрах «Журнал буфера обмена» — Вкл.,
- политик, запрещающих журнал, нет,
- залипших модификаторов нет,
- Windhawk — единственный мод отключён,
- клавиша Win сама по себе работает (Пуск открывается).

**Причина:** завис `TextInputHost.exe` — процесс, который эту панель рисует
(висел с 11:41). Служба тут ни при чём, она отдельная.

**Лечение** (в PowerShell, ничего не сносит, процесс поднимается сам):

```powershell
Get-Process TextInputHost | Stop-Process -Force
```

Всё. Win+V сразу заработал, история никуда не делась.

**Чего НЕ надо делать:** останавливать `cbdhsvc` — она защищённая, не даст, и не
в ней дело. Перезапускать explorer тоже не нужно.

Если однажды не поможет — следующий шаг перерегистрировать пакет оболочки
`MicrosoftWindows.Client.CBS`, но до этого не дошло.
